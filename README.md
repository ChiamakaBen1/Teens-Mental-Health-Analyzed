

 Project Overview
This project explores teenagers' mental health patterns using an interactive Power BI dashboard. It focuses on social media usage, sleep duration, stress, anxiety, and academic performance to identify patterns and provide meaningful insights.

 Project Objectives
- Analyze daily social media usage among teenagers.
- Examine sleep patterns and duration.
- Explore stress and anxiety levels.
- Investigate depression-positive labels.
- Examine patterns related to academic performance.
- Present findings through interactive visualizations.

Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Data Visualization

 Key Performance Indicators (KPIs)
- Total Teenagers: 1,200
- Average Social Media Usage: 4.54 hours
- Average Sleep Duration: 6.45 hours
- Depression-Positive Labels: 31

 Key Findings
- Average daily social media usage is 4.54 hours.
- Average sleep duration is 6.45 hours.
- 31 records have positive depression labels.
- Depression-positive records show higher average stress and anxiety scores and lower average sleep duration.

 Recommendations
- Encourage balanced social media usage.
- Promote healthy sleeping habits.
- Increase awareness of stress management.
- Encourage physical activities and healthy social interactions.
- Promote access to mental health education and professional support.

 Dashboard Features
- Interactive KPI cards.
- Social media usage analysis.
- Sleep duration analysis.
- Gender and age-based comparisons.
- Key findings and recommendations.
- Dashboard navigation buttons.

 Project Files
- Power BI Dashboard (.pbix)

 Disclaimer
This project is for educational and analytical purposes. The findings represent patterns within the dataset and should not be interpreted as clinical diagnoses or proof of causation.
